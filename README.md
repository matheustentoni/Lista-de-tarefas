# To Do List

Projeto de lista de tarefas desenvolvido com HTML, CSS e JavaScript.

Permite adicionar, concluir e remover tarefas de forma simples e rápida.

---

# Tecnologias
- HTML
- CSS
- JavaScript

---

#Funcionalidades
- Adicionar tarefas
- Marcar como concluída
- Remover tarefas

---

# Objetivo
Projeto criado para praticar lógica de programação e manipulação do DOM.
